# Automata Atlas

An interactive map of the Theory of Computing course (CSCE 4201, AUC, Fall 2026). Every session is a stop on the Chomsky hierarchy where you can run the machine, break it, and play the in-class activity.

- `index.html` is the whole site in one file (no server, works offline).
- `src/` holds the sources. Run `python3 src/build.py` to rebuild.

Course material and notation: Dr. Alia El Bolock, CSCE 4201.
